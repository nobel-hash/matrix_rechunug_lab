# Matrix Calculation Trainer

An interactive web application designed to help you learn matrix algebra and practice matrix calculation exercises.

## Run Locally

**Prerequisites:**  Node.js

Install the dependencies:
'bash'
->npm install 

Start the development server:
'bash' 
->npm run dev
